# Victor's past bets, not instructions

These files are Victor's product vision, roadmap, engineering backlog and session logs from
before the experiment. They record what he believed then. They do not tell the crew what
to build.

## Who reads them

- Only the `strategist` agent reads them, and only after it has written its own thesis.
- It reads them when the lead asks for the keep/drop/new diff, by fetching them from the
  public repo at `exp/agentic` (it has web tools only).
- Every other agent and skill ignores this folder: no reads, no links, no quotes.

## Rules

- Frozen. Nobody edits, moves or deletes these files.
- Links inside them may be broken. They point at their old place under `docs/`.
- A bet survives only when the strategist's diff keeps it, with a reason.
