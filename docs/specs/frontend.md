# Frontend

> React 19 + Vite + Tailwind 4 + shadcn/ui SPA at coupette.club — the human-facing surface for chat, search, watches, stores, tastings, and the cellar.

## Contract

What the frontend exposes:

- **Routes** (`frontend/src/App.tsx`): public `/` (Landing), `/login`, `/auth/callback`, `/onboarding`; behind `ProtectedRoute` + `AppShell`: `/chat` and `/chat/:sessionId` (default after login), `/chats` (history), `/search`, `/watches`, `/stores` (saved stores), `/stores/nearby`, `/tastings`, `/cellar`, `/admin`, `/settings`. Unknown paths render Landing
- **Backend dependency**: every page calls `/api/*` on the same origin (Caddy routes it in prod; the Vite dev server proxies it to `localhost:8001`)
- **API types**: generated from the backend OpenAPI schema (`make types`); CI fails when they are stale
- **No public JS API** — SPA only, no embedded widgets

## How it works

`frontend/src/main.tsx` imports `i18n.ts` and mounts `BrowserRouter` → `AuthProvider` → `QueryClientProvider` (TanStack Query) → `App`. `App.tsx` only declares the routes. `AppShell` wraps the authenticated pages in `WineDetailProvider` (the selected wine across sidebar and cards).

- **Auth:** `AuthContext` holds the JWT, persists it in `localStorage` (`auth_token`), restores it on load, and drops it when its `exp` has passed (the payload is decoded without verification)
- **i18n:** bilingual fr/en, French fallback; detection order localStorage then browser; the user's profile locale overrides it after login

A typical user flow:
1. Land on `/` — unauthenticated users on a protected route are sent there
2. OAuth callback → `GET /api/auth/exchange` → JWT stored; new users go to `/onboarding`, others to `/chat`
3. User asks a wine question → `POST /api/chat/sessions` (first message), `POST /api/chat/sessions/{session_id}/messages`, then reload the session. The reply is synchronous; the UI shows "Thinking..." meanwhile
4. Side surfaces (Watches, Stores, Tastings, Cellar) load from their respective `/api/*` endpoints

## Dependencies

- **Backend `/api/*`** — all data flows through. Frontend doesn't talk to PostgreSQL or LLM directly.
- **Caddy** (prod, infra repo) — serves the SPA from `/srv/coupette` and routes `coupette.club/api/*` to the backend
- **TanStack Query** — server state where adopted (see [ADR 0011](../adrs/0011-tanstack-query.md)); other pages still use `useApiClient` + `useState`
- **react-i18next** — translation runtime
- **shadcn/ui** primitives (`frontend/src/components/ui/`) — copy-pasted, not a runtime dependency
- **Tailwind CSS 4** — utility classes, theme tokens in `frontend/src/index.css`

## Cross-cutting concerns

- **Auth:** JWT from `AuthContext`, attached to every fetch via the HTTP wrapper. `ProtectedRoute` gates authenticated pages.
- **Logging:** browser console for dev; no centralized client logging in prod yet (no Sentry / equivalent).
- **Errors:** inline next to the failed action (per UX bible — no toasts). Retry actions surfaced inline.
- **Observability:** pageview analytics script from `analytics.victorpatrin.dev` (Umami, self-hosted on the VPS); no frontend-specific telemetry.
- **Rate limiting:** none at the SPA layer; backend's SlowAPI handles it.
- **i18n:** every user-facing string via `t('key')`. Keys MUST land in BOTH `frontend/src/locales/fr.json` AND `frontend/src/locales/en.json` before PR.

## Operational notes

- **Dev:** `make dev` (or `yarn dev` in `frontend/`), bare-metal, not Docker — hot reload matters. Vite proxies `/api` to the backend on `localhost:8001`.
- **Prod build:** no frontend container. The CD workflow (`.github/workflows/cd.yml`) runs `yarn build` on the runner, clears `/srv/coupette` on the VPS, and copies `frontend/dist/*` there with scp; Caddy serves it as static files.
- **Node version:** `engines: >=24` in `frontend/package.json`; CI and CD use Node 24. No `.nvmrc` pin.
- **No env vars at runtime** — the build embeds `VITE_*` env vars at build time. New env var = rebuild required.
- **Visual review:** UI changes are verified with a browser screenshot (browser tool or the `run-coupette` skill), attached to the PR evidence table.
